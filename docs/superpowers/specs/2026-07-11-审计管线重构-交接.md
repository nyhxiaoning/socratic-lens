## 0. 一句话：这个项目的真实意图（已澄清，覆盖 CLAUDE.md 旧表述）

用户有一条**造书管线**：输入 =（学生课本 + 教师用书），LLM 合成一本「AI 苏格拉底老师的教学蓝本」。
用户**对合成结果没信心**，要一个**自动审计器**回答：**「这本合成的书，能不能达成它原定的教学目标？」**，并把反馈打回造书管线。

- 教师 / 学生 / 教练 / 审计四个 agent，全是**产出审计信号的仪器**，不是目的本身。
- 书面向**全谱学习者**（不止 12 岁；有成人学真难内容的书，也有 K-12 基础内容的书）。
- 参照系是**破卷（Socratopia）**：`S:\Code\工作探索\破卷写书\背景.md`。
- 目标书样例：
  - `S:\Code\工作探索\破卷写书\english-book-七上-v2-师生合版\BOOK.md`（合成蓝本，21.8万字）
  - 源材料：`…\source-md\full.md`（学生课本 16.8万字）、`…\source-md-teacher\full.md`（**教师用书 25.6万字**）
  - `S:\Code\工作探索\破卷写书\vocab-book\`（金标准章打法：一章重审→当模板扩写→其余轻审）

## 1. CLAUDE.md 的偏差（记录准确，但描述的是一把瞄错靶的枪）

文档没写错字，但它忠实记录了当初照「审马原那种抽象书」思路造出来的工具。三处误导：

1. **「审计用户自己写的书」** → 错。真正对象是**验收「对现成教材的合成改写版」够不够教**，不是评判书的质量（外研版是国家审定教材，轮不到审）。
2. **「学生看不到原文，学生的困惑就是这本书的困惑」** → 万恶之源。旧读法「学生哪懂了=书哪清楚了」需要**真困惑**，在 K-12/基础内容上**直接失效**（大模型对基础内容不可能有真困惑，困惑是演的）。
   **正确读法：「合格学习者会问出的问题树 = 这本蓝本必须覆盖的边界。」照的是「覆盖」，不是「学习」。困惑真假不重要，覆盖缺口是真的。**
3. **审计产出「5 段 ===TAG=== 散文报告」** → 为「读 transcript 挖卡壳」造的。真正要的输出是**客观的**：知识锚点覆盖率 + 教材原题过没过 + 老师在哪一问卡壳。

→ 重构落地时要改 CLAUDE.md 背后的枪，不只是措辞。

## 2. 逼问逼出的核心结论（认识论层，最重要）

- **「学生真的学会了吗」这件事，破卷已经商用验证过（有付费用户/留存），是常量，每本新书继承，不重证。** 用户纠结的「没有人类锚来测学会没学会」是**伪命题**——那不是每本书要重做的功课。
- **fake learner 的困惑当「学习信号」是假的，当「蓝本探针」是真的**：agent 演的一问，逼出真问题「老师只拿蓝本，答得上吗？」——蓝本的覆盖窟窿是真的，与困惑真假无关。
- **残余风险（未解决）**：agent 扮低龄/基础学习者，问题分布是**歪的**——会问真孩子想不到的高级问题，问不出真孩子会卡的蠢问题。年级越低偏差越大。**这层探针误差消灭不了，只能管理。**（对应下面 #7）
- **「先给 learner 看内容介绍再装不会」是错的补丁**——那让它更懂、更像装傻的专家，且会顺着蓝本目录提问 → 自证覆盖。已否决。
- **AI 审 AI 造的书的死穴**：审计器若与生成器同源，只抓得到它自己不会犯的错；生成幻觉与审计盲区是**同一套盲区**，「通过」的真实含义只是「生成器犯的错是自洽的」。
- **「不同阶段用干净上下文的模型」≠ 独立**。清空上下文只擦记忆，擦不掉长在**权重**里的缺陷。同源模型盲区相关系数≈1，叠一百次方差不下降。独立性三层级：①换上下文（≈0）②换模型家族（不同厂/训练数据，才有真独立）③换立场+锚定源（拿源材料当 ground truth 逐条卡）。

## 3. 七条改造 + 依赖序（DAG）

```
   #3 拆 Fidelity / Sufficiency 两个审计   ← 认识论根：不写代码，一句话决定其余各条归哪半，最先做
        ├── Fidelity 腿 ──────────────┐        └── Sufficiency 腿 ──────────────┐
        │  #1 换独立模型(基建根)       │        │  #4 困惑→覆盖缺口(prompt层)     │
        │      audit 走不同厂/端点     │        │      重写创世口号                │
        │        │                     │        │        │                        │
        │  #2 源材料勾稽               │        │  #5 类型分流开关                 │
        │      拿源当 ground truth     │        │      前沿/基础→困惑采不采信      │
        │      (依赖#1，否则自证)      │        │        │                        │
        └────────────┬────────────────┘        └────────┴────────────────────────┘
                     └────────────┬──────────────────────┘
                          #6 对抗验证(横切质量层)  ← 只上🔴🟠、证伪立场；依赖#1(不同源才有意义)
                                   │
                          #7 真人兜底(仅 Sufficiency 腿) ← 制度决定，不阻塞代码；不做则 Suff. 读数没标定
```

**三条关键依赖：**
1. **#3 最先、免费**：是一个「划分决定」（审计在问 Fidelity 还是 Sufficiency），不是代码。定下后 #2 归 Fidelity 腿、#4/#5 归 Sufficiency 腿。不先做，后面互相打架。
2. **#1 是 #2 和 #6 的技术前提**：同源模型做勾稽/对抗=失忆版自审，信心是假的。
3. **两条腿性价比不对称**：
   - **Fidelity 腿（#3→#1→#2）**：不跑对话、不需要 fake learner、拿源当铁证、信号最可靠，**拦住「造书没信心」的大头**。
   - **Sufficiency 腿（#3→#4→#5→#7）**：要跑对话、要 fake learner、信号永远带探针误差、要真人兜底，**贵且软**。

### 两个维度的定义（#3 的产物）

| | Fidelity 保真度 | Sufficiency 自足度 |
|---|---|---|
| 问的问题 | 合成书有没有丢/歪源材料（尤其教师用书）里的教学目标、知识点、讲法？ | 老师只拿合成书（学生永不见源），能不能覆盖源能覆盖的？ |
| 靠什么判 | 拿合成书**逐条勾稽**源 | learner 当**覆盖探针** |
| 需要 fake 困惑吗 | **不需要** | 需要（且信号最不可靠） |
| 占「没信心」比重 | **大头** | 小头 |

## 4. 推荐的 spec 切分（本次锁第 1 个）

## 5. P0 技术落点（第 1 个 spec 的代码起点）

- `lib/llm.ts`：现所有 purpose **共用单一 `LLM_BASE_URL` + 单个 client**；`pickModel` 只能换模型**名**，换不了厂/端点。
  → 要改 `getClient`：让它**按 purpose 选独立 client**（audit 用一个不同厂/端点的 key+baseURL+model）。新增 env，如 `LLM_AUDIT_BASE_URL / LLM_AUDIT_API_KEY / LLM_AUDIT_MODEL`。
- `lib/audit.ts`：审计规则从「读 transcript 挖卡壳、出散文」改成「**拿源材料逐条勾稽**」——源清单第 X 条，在合成书哪一句落地？引出来；找不到=漏；落地但讲法变了=标记待人核。
- 源清单本身也用 LLM 抽，但产物是**结构化清单**（知识点/评价标准/教材原题及答案/教师标注易错点），人可扫一眼验。
- `prompts/`：新增 Fidelity 勾稽规则文件；旧 `audit_rules.md` 的 5 段散文协议**不适用** Fidelity 腿。

## 6. 未决问题（新会话不必现在答，但 Sufficiency spec 前必须答）

**#7：fake learner 探针误差兜在哪？** 用户连躲三轮未答。两个诚实选项：
- (a) 用户**本人定期抽样**：管线批量造完+审计粗筛完后，亲自扮一次零基础学生跟 AI 老师上一节改后的课（~10 分钟），给自动探针**校准零点**。破卷模式的可量产退化版。
- (b) **放弃出厂验证「学会了」**，只用 fake learner 验蓝本机械完备性（锚点覆盖/题目有解/老师不卡壳），明确承认「能否真正教会真孩子」出厂未知，靠上线数据补。

不做任一个，Sufficiency 审计就是**没标定过的仪器**：读数精密，但不知道偏多少。
