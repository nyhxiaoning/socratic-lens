# 你的任务：拿清单逐条核对教学对话

给你两样东西：
1. 一份**教学内容清单**（从上一步从源材料或书本原文抽的，JSON）。
2. 一段**教学对话 transcript**——一位 AI 老师（苏格拉底式）和一位学生之间的对话。
   每轮以 `【教师】` 或 `【学生】` 开头。

对清单里**每一条**，判断在对话中老师是否覆盖了这个点，输出三态之一：

- **landed 落地**：老师在对话中明确讲了、引导学生推导了这个点。给出 `synthQuote`——老师嘴里**最相关的一句原话**（逐字摘）。
- **morphed 变形**：落地了，但讲法/范围/例子变了（讲窄了、讲宽了、不完整、例子不对）。给 `synthQuote` + `note` 说明怎么变的。
- **dropped 漏**：对话中没有证据表明老师覆盖了这个点。**这是最要抓的**。`note` 说明可能为什么漏了（如"对话轮次不足"、"老师绕开了这个概念"）。

## 与「勾稽合成节」的关键区别

你审的不是一份静态文档——你审的是一段**真实对话**。对话天然：
- 知识点可能**分散在多轮对话**中——老师在一个轮次引出概念，学生在后续追问中深化。你不需要找"一段完整表述"，找到片段证据即可算落地。
- **学生的话也可以作为间接证据**——如果学生复述、总结、举例中体现了某个点被教到，即使老师当时没有长篇大论，也说明落地了（在 note 里注明"通过学生复述间接体现"）。
- 对话可能**被打断、绕路、回来**——如果老师在 tangent 之后回到了这个点，也算落地。
- 对话文本量大——你不需要逐句分析，只需要**对照清单条目有目标地扫描**。

## 判 exercise（教材原题）时

教材原题问的是"对话里有没有等价的练习"——不是原题原文，而是老师有没有让学生练到这个技能点。有等价练习→ landed/morphed，没有→ dropped。

## 硬规则

- `synthQuote` 必须是 transcript 里**老师说话的原句**（后续会做逐字校验——来自学生的引语标注 `(student says)`）。
- 拿不准落地与否时，倾向 **dropped**——审计宁可多报漏，不可漏报漏。
- **只输出 JSON**，不要任何解释文字、不要 markdown 代码围栏。结构：

{
  "rows": [
    { "checklistId": "kp1", "category": "knowledgePoint", "itemName": "...", "status": "landed", "synthQuote": "老师的原句" },
    { "checklistId": "ex1", "category": "exercise", "itemName": "...", "status": "dropped", "note": "对话中没有出现等价练习" }
  ],
  "verdict": "一句话总评：覆盖度如何——核心点是否都讲到了，漏的是不是要害。"
}

- category 取值：knowledgePoint / criteria / exercise / errorSpot（与清单条目对应）。
- 清单里每一条都必须在 rows 里出现一次，用相同的 id 作 checklistId。
